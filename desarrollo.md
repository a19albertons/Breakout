## Prerequisitos de desarrollo:

- Unity 6000.3.1f1 (esto indicación manual puede estar desactualizda, pero el propio UnityHub te indica la versión que debes usar)
Después de clonar el repositorio, se tiene que abrir un nuevo proyecto en Unity y seleccionar la carpeta raíz.

## Compilar la aplicación

- Abrir Unity con el proyecto
- Files > Build Profiles > Plataforma Linux > Build
